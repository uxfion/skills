# paper-read：标成"要看别处"的问题，答案常常就在库里同一篇论文的另一个附件里

- 来源：2026-11-06 一批精读 15 篇（UNSB、CycleGAN 等）。用户没有说过这件事；是 paper-read 文档通读的 subagent 翻读者报告时指出来的，主 agent 核对了报告原文。
- 状态：open。

## 看到的

读者按规矩只读笔记的读的版本那一份 PDF，正文说"见 arXiv 版"或"见补充材料"的问题都标成 要看别处，留着等用户问。可其中几篇，答案就在 Zotero 里同一条目的另一个附件上：

- CycleGAN：读的是 ICCV 版（Published-CVF）。λ、identity 权重、网络层数、训练设置等五个问题标了要看别处，正文写 "our arXiv version"（Sec. 4 p.4、Sec. 5.1.2–5.1.3 p.6、Sec. 5.2 p.6）。库里就有 arXiv v7（附件 `QQHZ6IDV`，18 页）。读者原话："A read in that version would answer all five. I did not read it into this note; every source in the note points into Published-CVF."
- VQ-I2I：读的是 arXiv v1，不含补充材料。损失权重 λ（Q3.4）、码本大小和维度（Q3.8）都在 ECCV 2022 的补充材料里。读者："可以把补充材料作为单独的包去取。"
- VQ-VAE：EMA 更新式（Q3.5.1）。NeurIPS 版 10 页、没有附录，读者猜 arXiv 1711.00937 可能带附录，没有查。
- ControlNet：零卷积的梯度、各条件的训练数据量在 ICCV 补充材料里；读者印象里 arXiv 2302.05543 把训练细节放进了正文，没有核实。

主 agent 给用户的总结把这些都列在"留着没答的问题（要看别处，你要的时候再查）"下。其实只要再取一个附件就能答，不必等用户。

## 为什么是个缺口

note-format.md 规定一篇笔记只在一个 PDF 里读（读的版本），每个出处的页码都按那份 PDF 算；要看别处的意思是"答案在论文之外：代码、补充材料"。有两种情况它没有分开：

- 同一篇论文的另一个版本或补充材料已经在库里。这时答案仍是"这篇论文说的"，只是不在读的版本里。
- 答案确实只在论文之外（代码仓库、网盘里的权重），或者库里没有那份文件。

前一种怎么办没写：读者能不能去读另一个附件、读了怎么标出处（读的版本之外的页码），还是交给主 agent 用另一次 take 去取。

## 要定的

- 要看别处的答案在库里另一个附件上时，由谁去读：读者自己，还是主 agent 收到报告后再派一次；`pr.py take` 能不能顺带列出同一条目的其他附件（标题、版本），让读者知道有。
- 这样的答案在笔记里怎么标出处，才不和读的版本的页码混在一起。
