# paper-read：从图上量出来的数值，笔记里没有标记的办法

- 来源：2026-11-06 精读 Cohen 2018（Distribution matching losses can hallucinate features）。用户没有说过这件事；是 paper-read 文档通读的 subagent 翻读者报告时指出来的，主 agent 核对了报告原文。
- 状态：open。

## 看到的

Cohen 2018 的正文没有给 Fig. 2 的任何数值，可稿件引它，靠的正是这张图（各档训练构成下分类器的判定比例、MAE）。读者从 PDF 里取出内嵌的 6 张 424×280 栅格图，逐像素量了柱高。报告原话："下面和笔记中的柱高、MAE 都是我从 PDF 内嵌的 6 张 424×280 栅格图逐像素量出来的（柱高误差约 ±1 个百分点，MAE 约 ±0.0005）。6 张图与面板的对应关系已逐一看图核实。"量取的脚本和取出的图已复制到本 issue 的 `-reference/fig2/`，结论在笔记 4RMPMRYG 里。

note-format.md 的标记只分"论文说的"（原文引文、出处）和"我的判断"，没有"从图上读出的近似值"这一类。读者只好在笔记里自己写了一段说明误差的话，下一个读者遇到同样的图可能写成别的样子，也可能干脆当原文数字用。

## 为什么要紧

一个从图上量的数和正文里的数，可信程度不一样：前者有读数误差，也可能对错了面板。稿件或决策用到它时，要能一眼看出它是量的、误差多大。paddleocr 的 `--charts` 把图转成表时也是"从图上读的值"，SKILL.md 要求对照图片核实，同一类东西。

## 要定的

- note-format 是否加一种标记（比如数值后面注"图上量取，约 ±x"），以及量取的方法要不要写进笔记（哪张图、哪个面板、怎么量的）。
- 量的过程（脚本、取出的图）要不要随包或笔记留下，供以后复核。

读者报告原文在本 issue 的 `-reference` 文件夹里。
